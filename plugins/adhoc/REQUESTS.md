- Roblox Studio plugin (“Color Companion”) with a draggable dark Material-3-style dock/float widget. Input a base color (#RRGGBB/#RGB/rgb/r,g,b), preview updates, choose mode: Complementary (hue-rotated + split complements) or Contrasting (selects hues/lightness maximizing WCAG contrast vs base with threshold + dedupe), pick 1–4 new swatches, optional Randomize. Swatches support lock/unlock persistence, Clear Locks, copy hex, toast status.
